# 서논술형 자동 채점 웹앱

## 실행 방법
```
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구성
- `rubric_data.py` : 채점 기준 데이터 (세트별 키워드 그룹, 오개념 트랩, 결론 방향, 모범 답안)
- `grading.py`     : 채점 엔진 (규칙 기반 매칭/판정 로직)
- `app.py`         : Streamlit UI

## 채점 로직 핵심 원칙
1. 조건에서 허용한 방법의 '의미'가 답안에 담기면 정확한 용어 없이도 인정 (required_groups의 키워드 중 하나만 있어도 그룹 충족)
2. 서논술형2에서 특정 설명 방법을 선택(괄호 표기)하면, 그 방법의 특성 표현(METHOD_PATTERNS)이 문장에 실제로 드러나는지 검사
3. 오개념 방지: 반대/대구 개념 키워드(opposite_keywords)나 흔한 오개념 표현(misconception_keywords)이 등장하면 감점 및 경고
4. 결론 방향 확인: conclusion_required / negation_check로 요구된 결론(예: "예술로 보기 어렵다")이 실제로 드러나는지, 부정 표현 없이 반대로 서술되지 않았는지 확인

## 한계 및 주의
이 앱은 키워드/패턴 기반 1차 자동 채점 도구입니다. 자유서술형 한국어 텍스트의 의미를 완벽히 판단하지는 못하므로,
'미흡'/'부분점수' 판정은 반드시 교사가 최종 검수 후 확정해야 합니다. 특히:
- 3세트 서논술형1 ㉠은 표 헤더("올림픽 경기에 비유")와 실제 요구 내용(대조 사례) 간 설계 모호성이 있어 관대하게 채점하도록 설정함
- '비유'라는 표현은 6대 설명 방법에 없으므로 오답으로 안내하되, 최종 인정 여부는 교사 재량
